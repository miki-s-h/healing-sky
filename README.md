# sora note（そら note）

空の写真をまとめた、癒しのためのWebサイトです。

🔗 **公開URL**: https://miki-s-h.github.io/healing-sky/

## コンセプト

趣味で撮りためてきた空の写真を一つのサイトにまとめ、自分自身が見返したときにも癒されるような場所を作りたいと思い、制作しました。ただ写真を並べるだけでなく、それぞれの写真に一言添えることで、その瞬間の空気感も一緒に残せるようにしています。

## 使用技術

- HTML
- CSS
- JavaScript（Intersection Observer API）

## こだわったポイント

- **ファーストビューの重なり表現**：トップ画像の上に文字を重ねて、印象的な導入にしました
- **スクロールでふわっと表示**：Intersection Observerを使い、各写真がスクロールに合わせてふわっと浮かび上がるようにしました
- **フッターの一文字アニメーション**：フッターの文字が一文字ずつ順番に表示される演出を加えました
- **写真ごとの一言キャプション**：写真だけでなく、その時感じたことを短い言葉で添えたりしています
- **レスポンシブ対応**：スマホ・PCそれぞれで写真が見切れないよう、表示方法を調整しました
